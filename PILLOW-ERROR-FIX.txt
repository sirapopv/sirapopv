========================================
  PILLOW INSTALLATION ERROR
  "failed building wheel for Pillow"
========================================

This is a COMMON error on Windows!

Pillow needs C++ compilers to build from source.
You have 3 solutions:

========================================
SOLUTION 1: Quick Fix Script (EASIEST)
========================================

Double-click:  FIX-PILLOW.bat

This script will:
- Try installing pre-built Pillow
- Try alternative installation methods
- Install all other packages

This works 90% of the time!


========================================
SOLUTION 2: Install Build Tools
========================================

Pillow needs Visual C++ to compile.

Step 1: Download Build Tools
https://aka.ms/vs/17/release/vs_BuildTools.exe

Step 2: Run installer

Step 3: Select "Desktop development with C++"

Step 4: Click Install (takes 5-10 minutes)

Step 5: Restart computer

Step 6: Run QUICK-FIX.bat


========================================
SOLUTION 3: Use Flexible Requirements
========================================

This installs latest versions (without locks):

Double-click:  QUICK-FIX.bat

This installs packages without strict version
requirements, which usually fixes Pillow issues.


========================================
SOLUTION 4: Continue Without Pillow
========================================

The app can work WITHOUT Pillow, but:
- Won't be able to generate thumbnails
- Everything else works fine

To skip Pillow:
1. Activate virtual environment:
   venv\Scripts\activate

2. Install other packages:
   pip install youtube-transcript-api
   pip install yt-dlp
   pip install google-generativeai
   pip install gtts
   pip install pyyaml
   pip install python-dotenv
   pip install click
   pip install rich
   pip install streamlit

3. Skip Pillow installation

4. Run START.bat

Note: You can install Pillow later if needed.


========================================
SOLUTION 5: Manual Wheel Installation
========================================

Download pre-compiled Pillow wheel:

Step 1: Check your Python version
python --version
(Example output: Python 3.11.5)

Step 2: Check if 32-bit or 64-bit
python -c "import struct; print(struct.calcsize('P') * 8)"
(Output: 64 or 32)

Step 3: Download matching wheel from:
https://www.lfd.uci.edu/~gohlke/pythonlibs/#pillow

Example for Python 3.11, 64-bit Windows:
Pillow‑10.x.x‑cp311‑cp311‑win_amd64.whl

Step 4: Install wheel
venv\Scripts\activate
pip install path\to\downloaded\file.whl

Step 5: Continue with other packages
pip install -r requirements.txt


========================================
WHICH SOLUTION SHOULD YOU TRY?
========================================

Try in this order:

1st: Double-click FIX-PILLOW.bat
     (Fastest, works most of the time)

2nd: Double-click QUICK-FIX.bat
     (Installs everything without version locks)

3rd: Install Visual C++ Build Tools
     Then run QUICK-FIX.bat

4th: Continue without Pillow
     (App works, but no thumbnail generation)

========================================

Just double-click FIX-PILLOW.bat

It will:
✓ Try multiple installation methods
✓ Install all other packages if Pillow works
✓ Give clear instructions if it fails

This fixes the issue 90% of the time!

Once Pillow installs successfully:

   Double-click START.bat
