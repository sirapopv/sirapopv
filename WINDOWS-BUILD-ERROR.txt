========================================
WHY IS THIS HAPPENING?
========================================

Pillow and Streamlit contain C/C++ code that needs
to be compiled for Windows.

Your computer needs these to compile:
- Visual C++ compiler
- Windows SDK
- Build tools

Without these, Python can't build the packages.

Solution: Install the build tools (see above)
